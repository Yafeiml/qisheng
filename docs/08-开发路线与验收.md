# 开发与验收

安装步骤见[部署说明](../deploy/README.md)，开发启动见[根说明](../README.md)。工具链以仓库清单与锁文件为准，不因安装新工具而自动升级依赖。

```sh
pnpm lint
pnpm typecheck
pnpm test
pnpm contracts:check
pnpm build
pnpm source:check
```

数据库集成测试需要隔离测试库；不得把会写入或清理数据的测试指向已有业务库。迁移检查需核验历史 SHA-256、全量重放及兼容性，不能以修改旧迁移消除错误。

## 核心验收

- 空安装创建主管理员与组织、密码登录、账号停用与会话失效；已有组织不能再次初始化，公开注册入口及旧注册 API 拒绝创建账号。
- CAP 关闭时可用，开启时必须有 Endpoint 与 Secret Key，并执行服务端验证。
- 满足资料、模型、审核和基础设施条件的活动可正常创建和执行。
- 素材整理、活动生成、失败重试、安全审核和人工批准。
- 审核后立即开放、预约开放、同企业活动重叠与既有取消边界。
- 管理员为明确成员创建网页账号；员工只能领取、确认和回填本人任务，真实性确认绑定当前内容版本。
- 桌面与窄屏表单控件、选择和提交，包含错误恢复。

## 外部验收

本地协议服务、fixture 与 synthetic 用于可重复验证，不代表真实模型质量、真实平台可获取率或审核通过率。真实供应商测试需用自己的账户和授权样本，可能产生费用。外部验真与指标可选，未启用的能力不应阻断首次安装，启用后必须遵守相应验证门禁。

源码公开前另外复核秘密、Git 历史、媒体来源、第三方声明及许可证，并从不含私有 Git 历史的审查快照独立建仓。首版原创部分采用 [Apache License 2.0](../LICENSE)，第三方组件保留各自许可。`source:check` 失败需要处理对应发布阻碍，不能被简单解释为应用运行失败。
