# 平台参数中心

平台管理员在参数设置维护运行配置；工作空间、企业与员工身份不能读取或修改平台凭据。模型供应商与作用域路由在模型配置页维护。

| 分组 | 内容 |
| --- | --- |
| 常用 | 平台名称、时区、任务有效期与界面信息 |
| 生成、检索与 Worker | 并发、租约、重试、检索策略和能力配置 |
| 存储 | 默认本机存储、可选 S3、签名交付与 S3 生命周期治理 |
| 内容安全 | 图文模型或独立服务、测试与规则 |
| 安全 | 可选 CAP、会话、可选短信兼容通道与指标签名 |
| 小程序、通知 | 可选微信接入、员工通知和模型故障邮件 |

支付、商业申请审批和组织同步配置不属于当前运行功能。历史参数在数据库中保留不表示继续启用。

## CAP 可选验证

CAP 默认关闭，账号密码登录可以独立使用；不提供公开注册。启用前必须填写：

- **Cap 验证服务 Endpoint**：自己的验证服务地址。
- **Cap 验证服务 Secret Key**：服务端私钥，加密保存，不回显。

保存后由服务端校验配置及验证结果，不能只依赖浏览器完成验证。地址仍受网络安全策略约束，不为方便而整体关闭 SSRF 保护。

## 密钥与生效

Secret 以独立关联数据加密存储，普通 API 与审计只返回掩码和配置状态。密钥字段留空是否保留旧值以页面说明为准，不用复制掩码当成新密钥。更新使用版本校验、操作原因和审计，避免覆盖其他管理员的修改。

部分 API 参数动态生效；Worker 的进程配置按页面提示滚动重启。内容审核方式、模型、地址或实际密钥变化后须重新验证。

数据库、Redis、应用签名及凭据加密主密钥保留在受保护的部署环境中，避免错误后台修改破坏启动。升级沿用现有加密密钥。安装示例只含占位值，真实配置不提交 Git 或写入镜像。
