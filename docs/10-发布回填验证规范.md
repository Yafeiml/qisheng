# 发布回填与可选验真

员工提交链接表示提交了发布事实，不能仅凭链接存在就宣称验证了账号归属、图文一致性、曝光或成交。默认员工网页支持手动发布和回填；外部验真、回读和指标供应商按需接入，不是首次安装条件。

## 链接与去重

- 接受受支持的公开长链、短链及包含链接的分享文本。
- 提取唯一候选 URL，严格校验协议、域名边界与路径，不以简单字符串后缀信任域名。
- 短链解析和每次重定向重新执行 SSRF、DNS、目标与大小限制，拒绝内网及不支持的跳转。
- 有明确内容 ID 时生成稳定 canonical key；不能确认的结果不得猜测。
- 同一公开内容不能证明多个任务完成，全局占用依靠唯一约束与原子事务。
- 冲突提示不披露另一个工作空间、企业或员工的身份。

## 内容匹配

启用相应适配器后，匹配对象是任务当前有效的员工内容快照。文本比较可组合规范化、字符/词语相似度、关键事实和主题实体；图片比较依据实际交付图片的指纹和已配置策略。规范化用于比较，不回写员工原文，也不能通过删除否定词或数字掩盖差异。

验证策略有版本和阈值。允许合理格式变化，不接受只有主题相近但主体或关键事实不同的内容。没有图片证据不能宣称完成独立图片核验。账号名称不作为匹配依据，系统不保存小红书登录凭据。

| 结果 | 处理 |
| --- | --- |
| VALID | 当前验证策略的证据充分，保留版本和观察时间 |
| DUPLICATE | 已被其他任务使用，不泄露其归属 |
| INVALID | 有明确不匹配证据，按复核流程处理 |
| MANUAL_REVIEW | 证据不足或处于灰区，需要人工核查 |
| UNAVAILABLE / 技术失败 | 允许重试或复核，不能自动认定员工作弊 |

## 公开指标

默认由管理员人工复核发布链接，自动回读是可选功能。可选回读节点使用独立签名身份、租约和幂等回写。只读取完成验证所需的公开内容及总量指标；缺失指标保留未知，不写成零。同机模式由主后台加密保存供应商 Token，并只随有效任务下发给指定节点；密钥和 Token 不回显到主网页，也不进入业务快照或报告原文。细节见[回读接入边界](publication/readback-integration.md)。

真实外部验收使用[公开链接评测](../benchmarks/publication/README.md)，fixture 和 synthetic 不能作为生产策略证据。人工处置记录操作者、原因和证据；不以测试通过承诺平台审核或内容长期可访问。
