# 平台生成测试台

入口：`/platform/generation-lab`（运行与 AI → 生成测试台）。仅 `PLATFORM` 范围且拥有 `platform.model.manage` 的管理员可访问；保存为正式配置还需 `platform.settings.manage`。

## 使用流程

1. 选择企业、填写活动需求和检索关键词、选择内容方向及图片风格，点击检查素材。
2. 检查文字依据和匹配分数，选择参考图、Logo，或上传仅用于测试的临时参考图（必须填写说明）。资料库图片和临时图片合计最多 3 张。
3. 可在本版本临时调整基础提示词、内容方向和图片风格提示词。生成文案调用母版与员工文案各一次；生成海报只调用生图一次，复用已有/手动编辑的文案；完整测试共三次生成调用。素材检查另可能有一次向量检索调用。
4. 已提交的版本不可修改。复制版本保留事实、提示词、文案、参考图片身份和构图种子，再进行显式的下一次实验。不同版本可并排对比。修改需求或检索关键词使用新建测试（保留当前表单值供调整）。
5. 完整图文结果可以手动点击“审核一次”；不自动审核、不自动重试。审核配置需通过已有的连通性检查。Logo 使用正式流程的原图合成，不进入生图模型、不进行单独偏差评分。
6. 满意后可新增内容方向、图片风格、当前企业活动模板或全局基础提示词新版本。正式配置保存使用现有乐观锁与审计机制；活动模板不包括临时附件或临时提示词，调整过的预设需要先保存并在新的测试中选用。保存操作不修改已有活动。

## 隔离与追溯

- 使用真实企业范围及资料授权/共享能力校验。临时参考图不写入品牌资料库。
- 共用正式素材冻结函数、RoutedGenerationAdapter、供应商凭证解密、并发限制和熔断、图片读取/校验、Logo 合成、敏感规则与整体审核。实验不会创建虚构的活动或员工任务。
- 独立数据库任务记录，Worker 每 3 秒轮询，单实例一次执行一项。原子状态转换与心跳阻止多 Worker 重复领取；过期执行终止为 INTERRUPTED，不重新排队，避免未知供应商结果引起重复消费。未完成的素材检查超过 10 分钟终止，不自动重发。
- 路由在检查素材时冻结；测试将模型内部重试次数限制为 1、关闭备用模型回退。当前凭证在执行时安全读取，不存进版本或调用详情。
- 每次实际生成调用前写入记录，保存实际提示词、模型标识、参数、参考图哈希、耗时、返回用量和可核算费用。审查调用记录文本依据、审核规则和最终海报哈希。调用中断的 STARTED 记录表示结果/费用待确认，不表示免费。
- 供应商价格或用量缺失标为未知。币种沿用供应商价格配置，不在缺少币种声明时跨供应商汇总金额；估算不是供应商账单。检索失败记录也保留，但失败的供应商接口可能无法返回模型用量。
- 只显示安全错误码，不保存供应商异常原文中的凭证或签名地址。
- 临时图片、结果图片保存在平台专属表中，不影响企业存储额度；单张上传 4 MB、解码像素上限 2500 万、规范化图片最大 4 MB、海报最大 12 MB。历史不自动清理；管理员主动归档会删除该测试的图片二进制，保留调用与提示词记录，操作前 UI 明确确认。

## 数据库与发布

迁移 `20260928010000_generation_lab` 仅新增 `generation_lab_runs`、`generation_lab_assets`、`generation_lab_calls` 及其索引，旧 Worker 不读取这些表。已在专用本地影子库验证全量迁移与 schema diff，以及独立 schema 内 BEGIN / ROLLBACK。精确 SHA-256 登记于 `deploy/migration-policy.json`。

安装与升级见[自托管说明](../deploy/README.md)，使用相同版本的 API、Web 与 Worker 及相应兼容迁移。

本地页面验证使用隔离 API fixture，不向真实供应商付费调用。正式生成协议回归使用本地 HTTP 模拟供应商；真实图片质量、真实供应商用量/账单需要用户用自己的配置进行一次样本验收，不能以模拟测试代替。
