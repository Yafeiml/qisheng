# 内容安全审核

配置入口是自己部署的 `/platform/settings/content-safety`，仅平台管理员可配置。正式生成必须具备有效的图文审核配置，网络故障、超时、非法响应或漏审图片不能视为通过。

## 使用现有模型

1. 选择现有多模态模型及已配置的供应商。
2. 选择支持图片理解的模型 ID。只有文本能力或只支持生图的模型不能替代。
3. 保存后测试图文审核，检查正常图文与仅出现在图片中的危险内容。
4. 按页面提示重启 Worker，使其读取新配置。

模型模式复用供应商地址与加密密钥。当前兼容适配要求 Chat Completions、图片输入和结构化审核响应；实际供应商是否支持需自行验证。测试可能产生费用。

成功记录不按短时 TTL 失效；模型、地址、实际密钥、超时或规则版本改变后原结果不再适用。当前配置最新测试失败会撤销旧通过状态。测试只验证接入和基础能力，不能代替业务样本的误判评估。

| 结果 | 处理 |
| --- | --- |
| PASS | 进入既有人工批准流程 |
| REVIEW | 保留风险，按权限检查并处理警告 |
| BLOCK | 存在不可忽略项，需要处理或重新生成 |

审核覆盖正文、图片画面和图片文字，保留针对医疗营销等已确认漏判的规则。资料真实不等于任何渠道都可宣传，不以变形字、拆字或符号隔离规避规则。待审核内容中的指令作为数据处理。

## 独立审核服务

也可配置实现本项目 `requestId + text + images` 与 `PASS/REVIEW/BLOCK` 契约的独立 HTTPS 服务。普通模型 `/v1` Base URL 不是该服务契约。切换方式保留历史凭据与证据，不复制或回显模型密钥。

审核服务异常保留技术失败和成品证据，不自动当作安全通过，也不应为审核网络错误不断重新付费生图。人工批准与模型通过均不构成平台审核保证。
