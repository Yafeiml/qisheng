# 内容生成风格

平台配置入口为自己部署的 `/platform/settings/content-style`。企业创建活动使用通用主题与传播要求，并可选择内容方向、图片风格、提示词或活动模板；不再默认采用医疗选择式方案。

内置方向与图片风格可以由平台管理员维护，新增、排序、指定默认和停用。已有预设保留稳定 ID，使用停用代替破坏历史引用的删除。配置使用版本校验，冲突时保留编辑草稿并提示重新加载。

## 输入与冻结

- 本次活动目标、已授权素材、选择的方向及图片风格共同参与生成。
- 不能由风格推导出资料里没有的经历、身份、效果、优惠或排名。
- 创建时保存实际配置快照，Worker 重试与修订沿用活动输入，不自动改成后来平台的新默认。
- 管理员自定义文本和历史快照保留；只对精确匹配的未修改旧内置默认作兼容处理。
- 企业明确要求的篇幅、语气和视觉倾向优先于一般编辑建议，事实与安全约束始终生效。

文案长度、段落和 Emoji 是可调软目标，不是曝光公式，也不能为凑格式新增付费重试或删除必要风险说明。图片生成仍需人工核对主体、文字和真实素材保真程度，synthetic 不能代表真实模型质量。
