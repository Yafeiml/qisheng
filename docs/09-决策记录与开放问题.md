# 当前决策与待办

## 已确认

- 产品保持企业与员工内容共创，恢复通用生成，不把医疗行业选择式方案作为默认入口。
- 正式管理端使用安装向导和账号密码登录；CAP 可选，默认关闭。
- 员工网页为默认接入，由管理员为明确成员创建账号并设置初始密码；小程序是可选客户端。
- 员工只领取、确认真实、手动发布与回填，不承担活动策略和提示词工作。
- 移除商业交易、合同、销售申请与审批及三方组织同步模块；保留业务审计和已执行迁移，退休数据结构通过维护迁移清理。
- 生成只使用真实模型、审核、资料、权限及基础设施条件，不设置内部用量余额。
- 活动不强制提前 8 小时，同企业允许活动窗口重叠。
- 默认 Compose 安装不依赖特定主机、面板、SSH 网关或镜像中转。
- 保留内容安全、真实资料和权限隔离修复；不以变形字、拆词或符号规避审核。
- 首版社区源码从审查快照建立独立干净历史并公开，原创部分采用 [Apache License 2.0](../LICENSE)；第三方组件保留各自许可。

## 未决定或待外部验证

- 使用者需要配置并验证自己的真实模型和图文审核。新安装默认本机存储，S3 按需配置并验证。
- 公开搜索曝光、GEO 引用和成交需要独立外部证据，内部覆盖统计不能替代。
- 媒体、字体与第三方改编的分发权利需在公开前单独复核。

旧设计中的套餐销售、合同终止、仅限小程序和强制短信等约束已不适用于当前分支。实现细节以仍在使用的源码、迁移和当前文档为准。
