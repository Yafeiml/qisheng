# 可选短信兼容登录

正式管理入口采用账号密码，首次安装无需购买短信服务。此文仅供选择保留手机号兼容入口的部署者参考，不代表默认登录流程。

平台“安全设置 → 管理员短信登录”可配置阿里云 AccessKey ID、Secret、签名和模板。使用自己的最小权限账户，密钥加密保存，不写入源码、问题单或前端。短信发送测试可能按自己的套餐收费。

测试验证码不能用来登录。正式短信仍执行验证码有效期、冷却、尝试次数、身份和限流校验；发送失败不得保留可用验证码，也不得回退到固定开发验证码。生产环境禁止启用开发鉴权。

阿里云适配使用官方 SDK 调用其短信接口；若选择 HTTP 通道，按页面说明配置自己的网关和安全参数。短信配置独立于默认密码登录，不应因未配置短信而阻止密码账号使用。
