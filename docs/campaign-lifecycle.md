# 活动排期与取消规则

“执行中”包括审核通过等待开放的活动及已向员工开放的活动，界面区分等待开放与员工执行。员工内容仅在审核完成且到达开放时间后解锁。

## 开放时间

- 不再强制提前 8 小时准备，可以选择审核后立即开放或未来时间预约。
- 创建时的预定时间已过，审核时可按立即开放处理，并从实际开放时间计算截止时间。
- 显式预约与改期必须符合后端时间校验，不能任意回填历史时间。
- 同一企业的多个活动窗口允许重叠，不因另一活动正在进行而拒绝创建或审核。
- 时间约束取消不影响权限、成员资格、安全审核及人工批准要求。

| 阶段 | 开放条件与操作 |
| --- | --- |
| 生成中 / 生成失败 | 不开放，可取消或重试失败项 |
| 待审核 | 内容完整、无阻断后才可批准；可处理审核或取消 |
| 已审核、开放前 | 按正式时间开放，可按权限改期、撤销批准或取消 |
| 已向员工开放 / 已结束 | 保留排期与素材，查看执行与回填；不可取消或覆盖已交付内容 |

撤销批准回到待审核，取消进入已取消历史。未审核活动不会仅因预定时间已过就禁止取消；旧的未交付逾期任务可在重新审核时恢复锁定并重算截止。

取消通过工作项状态和租约处理，停止未完成的生成与未开放任务，并返回任务影响数量。任务曝光后的操作边界不因取消 8 小时限制而放宽。
