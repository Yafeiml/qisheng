# 素材可用性与版本处理

此说明保留资料校验修复中的通用技术结论，不包含原客户、人物、生产查询结果或私有操作回执。

## 证据校验

实体引用允许全角/半角及空白格式差异，但不能删除否定词、改写数字或模糊主体。实体名称确实出现在指定来源时，可使用原名作为最小证据；没有依据的附带实体不能进入检索元数据。若虚构信息已混入生成摘要，应标记处理失败，不发布伪造摘要，也不要求用户补交无关资料。

人物图像不能凭文件名或人脸推断姓名、职称与所属机构；需要可核对的说明及授权。一般环境图不应被要求填写与用途无关的履历或参数。

## 版本与编辑

- 高版本停用后，仍应能编辑当前有效的版本；版本号按整个系列最大值递增，不复用历史编号。
- 新版本完成前保留旧版本，不能跳过另一个正在处理或有效的新版本并行覆盖。
- 补充说明或重新检查原资料沿用现有文件，不能无故要求重复上传。
- 列表按需预览附件，长说明留在详情；编辑返回保留未保存输入。
- 更新保留历史引用，不物理删除仍被旧活动使用的对象。

重新检查可能调用已配置模型。接口权限、作用域、处理状态和并发校验继续生效，不能用重试绕过授权与安全要求。
