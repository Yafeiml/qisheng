# 历史实现说明

本分支已转为通用自托管系统。旧商业版的 Sprint 流水、私有部署拓扑与上线回执、供应商实测账户记录、医疗客户研究和已退休功能说明不进入公开候选文档。原始分支仍保存历史实现；当前安装不依赖这些记录。

保留的技术原则已经合并到现行文档：

- 组织、企业和员工身份隔离，后台权限与员工任务分离。
- 素材授权与不可变版本，活动冻结实际证据和生成配置。
- 队列租约、幂等重试及逐项状态收敛。
- 图文安全失败关闭、人工审核和外部验真证据边界。
- 兼容迁移、加密主密钥延续、明确镜像版本和运行健康检查。

数据库中可能继续保留旧支付、合同、审批及目录同步结构，这是升级兼容边界，不表示当前版本仍有相应运行模块。不要通过删表或修改旧迁移来清理文档中的历史概念。
