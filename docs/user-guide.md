# 企声发布操作说明

企声发布面向一家企业或一个集团：管理员整理真实、已授权的企业资料，组织小红书营销活动，为参与员工生成独立图文；员工确认内容符合自己的真实情况后手动发布，回填链接，再由管理员复核和查看效果。

首次部署请先阅读[部署与常见问题](deployment.md)。本说明按首版实际界面编写：运营功能位于企业工作台，模型、存储、审核和回读位于系统设置。菜单会随账号权限变化。

## 1. 完成首次安装并登录

1. 打开部署者提供的 `http://服务器IP:端口/setup`，也可以通过已配置的域名访问。
2. 输入首次安装凭证，填写主管理员账号、姓名和密码，选择单企业或集团，并填写组织名称。安装凭证由部署者在受信任终端查看，获取方法见[部署说明](deployment.md#3-网页初始化)。
3. 提交后即显示“安装完成”，进入工作台。安装向导只创建管理员和组织，不要求填写模型、审核或存储配置。
4. 后续通过 `/login` 使用账号密码登录。系统没有公开注册入口，其他账号由管理员创建。

单企业安装会自动建立一家企业。集团安装完成后，先在“集团与企业”中新增下属企业，再进入该企业开展运营。有多个获授权企业时，通过当前企业选择器切换；创建活动、成员管理和数据查看均受当前企业范围约束。

新安装默认使用本机存储，初次使用无需购买对象存储或填写 S3 密钥。主管理员拥有初始系统配置和组织管理权限；新增管理员应按职责授权。

## 2. 配置生成与审核能力

安装完成即可管理组织和账号。正式生成图文前，还需配置自己的模型和图文审核服务，相关调用费用由部署者的供应商账户承担。

### 模型配置

在“系统设置 → 模型配置”（`/platform/models`）中：

1. 进入“供应商”标签，添加供应商名称、API 地址和自己的密钥，读取可用模型。
2. 返回“模型选择”，配置用途并保存。
3. 按页面就绪检查验证连接、能力和路由；列表里能看到模型，不代表它已经通过实际生成验收。

| 用途 | 首版要求 | 说明 |
| --- | --- | --- |
| 文案模型 | 必填 | 生成员工活动文案。 |
| 生图模型 | 必填 | 生成活动配图。 |
| Embedding 模型 | 可选 | 留空使用本地基础检索；普通聊天模型不能直接当作 Embedding 接口填写。 |
| 资料理解模型 | 可选 | 留空跟随文案模型；处理图片资料时，实际使用的模型需要支持图片输入。 |

不同用途可以选择不同供应商。密钥保存后不回显；更换供应商或模型后，应重新检查当前配置的能力和就绪状态。测试和生成都可能产生供应商费用。

### 图文审核

在“系统设置 → 内容审核”中选择受支持的审核模式，保存后执行“测试图文审核”。根据页面提示验证当前配置，再重启 Worker 使运行中的处理模块加载新配置，具体命令见[部署说明](deployment.md#7-服务检查与维护)。

未配置有效模型、未通过图文审核验证，或队列没有真实消费者时，系统会阻止对应生成和分发操作。请按门禁提示补齐原因，不要通过关闭审核或修改数据库绕过。

## 3. 添加管理员与参与员工

后台账号与员工发布身份分开管理：拥有后台角色不会自动加入员工名单，也不会自动收到员工任务。

### 后台用户

在“后台用户”中新增账号、设置初始密码并授予角色。集团管理员可以按授权范围管理集团及下属企业；企业角色只处理获授权企业的业务。系统配置权限另行控制，企业业务角色不会自动获得模型、存储、密钥或系统安全设置权限。

### 员工与网页账号

1. 在目标企业的“员工管理”中维护成员；需要批量导入时，先下载页面提供的 CSV 模板，按模板填写后导入。
2. 核对成员所属企业、状态以及是否参与后续活动。停用、暂停参与或豁免会影响任务资格。
3. 为需要网页发布的成员创建网页账号和初始密码，通过安全渠道交给本人。
4. 员工访问 `/employee`，使用管理员分配的账号密码登录。

若员工看到“尚未加入发布团队”，先检查网页账号是否绑定了正确成员，以及该成员的任务资格。不要用新建重复成员来代替排查原绑定关系。

## 4. 整理素材、事实和宣传重点

在“素材中心”维护用于生成的企业资料与素材：

- 品牌、产品、门店、服务等可核实的信息，以及可公开表达的事实依据。
- 已获得使用授权的图片和资料，核对适用范围、授权状态及有效期。
- 本次营销希望说明的重点、内容方向、风格，以及需要避免的说法。

生成前先检查资料是否仍然准确、授权是否仍然有效。资料更新或授权变更后，应重新检查受影响的内容；已生成图文也需要人工判断。

GEO 在本系统中主要体现为对宣传重点、名称与别名、用户问题和主题的组织，以及对员工最终文案覆盖情况的分析。它帮助企业减少信息不一致和内容遗漏，不代表小红书推荐权重、搜索排名、外部 AI 引用率、曝光或成交承诺。

## 5. 创建活动、生成并审核

1. 进入目标企业，点击“创建活动”，填写运营目标、内容方向、提示词及图片风格等信息。
2. 检查参与成员和素材依据，按页面提示处理必要阻断项。
3. 发起生成，查看任务中心或活动详情中的进度。系统按参与成员准备独立内容，不应把同一篇成稿直接当作所有员工的真实经历。
4. 管理员检查文案、图片、事实依据、宣传风险和员工适用性。生成内容需要人工批准后才能进入发布安排。
5. 选择立即开放或预约开放。员工只会在活动开放且本人有资格时看到对应任务；同一企业可分别安排多个活动。

生成失败时先查看具体任务的错误原因、模型配置和处理异常页面，确认问题解除后再按页面允许的操作重试。重试可能重新产生供应商费用，不应重复点击生成来探测服务是否恢复。

## 6. 员工确认真实、手动发布并回填

员工在 `/employee` 的“我的内容任务”中：

1. 领取任务，阅读当前版本的文案和图片。
2. 确认内容符合本人的真实情况。内容不准确时先联系管理员修正，不能为了完成任务确认虚构经历。
3. 确认后复制文案、保存图片，前往小红书自行发布。系统不索取小红书登录密码，也不代替员工操作其账号。
4. 发布后复制公开笔记链接或分享文本，回到任务页面提交。

真实性确认绑定内容版本。内容被退回或修改、版本变化后，需要重新确认；提交接口也会核查这一条件。员工只能访问本人有效成员身份下的任务。

HTTP IP 页面可能无法使用浏览器安全剪贴板能力。遇到复制受限时，使用页面提供的普通复制方式或手动选取文本，不需要为了完成安装先配置域名。

## 7. 管理员人工复核发布链接

默认使用人工复核。员工提交链接后显示待核实，不会仅凭“提交了一个链接”就认定验证通过。

在企业工作台的“发布验真”中，打开待处理项，核对链接、当前任务内容和实际发布情况，再按页面操作记录复核结果及原因。重复链接、失效链接、内容不一致等情况需要单独处理；技术故障不能直接认定员工作弊。

人工确认与自动核验分别留痕。没有接入自动指标回读时，点赞、评论和收藏不会自动更新；缺失指标表示未知，不应解释为零。

## 8. 按需启用自动回读

自动回读用于查询公开笔记内容及互动指标，默认关闭。它不影响安装、登录、素材管理或员工回填，也不代替员工真实性确认。

1. 部署者按[同机回读部署步骤](deployment.md#6-可选同机自动回读)启动可选回读容器；无需独立服务器或节点面板。
2. 系统管理员进入“发布复核与回读”（`/platform/readback`），填写并保存自己的兼容公开 HTTPS 笔记详情接口和供应商 Token。项目不附带供应商地址、账号或服务。
3. 填写有权核查的样本笔记链接，确认可能产生费用后再执行样本验证。
4. 当前配置通过验证、同机身份已准备好后，再启用自动回读。接口或 Token 改变后需要重新验证；跨接口主机更换地址时须重新输入 Token。

新提交的回填按约 24 小时后的计划查询，不会因为打开后台页面立即查询所有笔记。关闭自动回读后停止领取新任务；未领取及后续失败、过期的任务转交人工，原租约内已经完成的有效结果仍可保留。

“自动回读未启用（可选）”是正常状态。同机节点可以在线待命，同时保持功能关闭；没有到期任务或功能关闭时不会查询供应商。

## 9. 查看执行情况与 GEO 内容覆盖

数据分析用于查看授权范围内的活动执行与发布情况。内容覆盖分析（`/console/geo`）可查看宣传重点和主题资产、最终文案重点提及、问题主题覆盖，以及活动趋势和集团内企业比较。

复盘时区分三种信息：

| 信息 | 代表什么 |
| --- | --- |
| 任务与复核状态 | 系统内员工任务的执行、回填及处理情况。 |
| GEO 本地覆盖 | 本系统资料、目标与最终文案是否覆盖已维护的名称、别名或主题。 |
| 外部公开指标 | 启用兼容供应商并成功查询后记录的观察值，有自己的观察时间与可用性限制。 |

这些信息不能直接推导外部平台推荐、排名、AI 收录或实际销售结果。截图和演示数据仅用于解释操作，不作为真实投放效果证据。

## 常见操作问题

| 情况 | 先检查什么 |
| --- | --- |
| 看不到某个菜单 | 当前账号的功能权限，以及是否进入正确企业。 |
| 集团安装后不能创建活动 | 是否已新增下属企业，并选择了目标企业。 |
| 管理员能登录，员工没有任务 | 后台角色不会自动成为员工；检查员工绑定、参与状态、活动开放时间和任务分配。 |
| 已确认真实仍不能提交 | 内容版本可能改变、任务可能被退回或已失效；刷新后重新核对当前版本。 |
| 模型已经保存但仍不能生成 | 查看模型能力、审核验证、Worker 消费者和门禁的具体阻断原因。 |
| 上传或图片加载失败 | 查看存储设置、磁盘容量、签名是否过期，以及 S3 的访问地址和 CORS；详见部署排障。 |
| 没有点赞、评论和收藏数据 | 默认人工复核不查询指标；检查可选回读是否启用、工作单是否到期及供应商是否返回指标。 |
| 想把已有本机文件切到 S3 | 首版有业务文件或在途任务时拒绝直接切换，不提供自动迁移；应保留原后端并单独规划迁移。 |

管理员修改权限、存储、审核或安全设置前，应了解影响范围。故障排查和日志收集方法见[部署与常见问题](deployment.md#8-常见问题处理)。
