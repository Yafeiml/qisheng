# 页面与体验架构

默认使用同一 Web 应用提供管理和员工网页，按权限显示入口。

| 路径 | 用途 |
| --- | --- |
| `/setup` | 首次安装创建管理员和组织后完成安装，默认本机存储 |
| `/login` | 正式账号密码登录 |
| `/platform` | 模型、系统设置和运行治理 |
| `/console` | 企业活动、成员、资料、审核与效果 |
| `/employee` | 管理员创建并绑定成员的账号登录、本人任务、图文领取及回填 |

企业维护真实素材、成员及活动。活动使用通用主题、传播要求、模板、内容方向和图片风格，员工不填写生成提示词或账号策略。生成后集中处理失败与审核，明确开放时间和提交期限。

管理员维护企业、成员和活动，生成条件直接展示模型、审核、资料及基础设施状态。

模型、可选 S3、内容安全和系统安全由系统管理员在安装后管理，不属于安装向导步骤。CAP、邮件、短信与小程序均按需启用。普通账号不被邮箱补全或销售审批强制阻断首次使用。

桌面工作区使用可用宽度，窄屏保持可操作；表格只在自身容器滚动，不引起页面溢出。表单控制容器间距，避免输入框与说明卡堆叠。所有 checkbox、radio、select 和按钮必须检查尺寸、焦点、禁用、选中与提交反馈，不能仅依靠浏览器默认样式。
