# ADR-001：主数据库选择 PostgreSQL

- 状态：已接受
- 初始日期：2026-08-27
- 自托管文档更新：2026-10-15

## 决策

采用 PostgreSQL 保存多工作空间业务事实、不可变业务快照、规范链接唯一约束、并发状态转换、审计和版本化元数据。正式结构由 Prisma 与已登记迁移管理；Redis 保存队列、租约和短期状态。

## 原因

- 部分唯一索引与事务适合回填去重和状态一致性。
- JSONB 适合规则快照和结构化模型元数据，核心查询字段仍保持关系结构。
- 聚合、窗口函数与索引支持企业活动及审计查询。
- pgvector 支持可选向量检索；是否启用外部向量模型与数据库迁移所需扩展是不同配置。

## 影响

安装者使用自己的数据库、角色和私有网络，不依赖原开发机的容器名称或账户。扩展要求、迁移权限和启动顺序见[安装说明](../../deploy/README.md)。所有迁移需要兼顾空库安装和已有库升级，不修改已登记历史，不用 `db push` 代替升级。

选用 PostgreSQL 不等于自动获得工作空间隔离，应用层鉴权、查询范围和数据库约束仍需共同执行。
