# 内容方向与图片风格预设

## 平台维护

在 `/platform/settings/content-style` 查看文案与图片的基础要求、内容方向和图片风格。每项保留稳定 ID；已有引用的项使用停用而不是删除。配置整体以版本号防止并发覆盖，保存写入审计。

基础要求与单项预设分别保存，不能假设保存某项预设会提交其他未保存草稿。启用项与默认项的校验以界面和 API 返回为准。

## 企业使用

创建活动时选择可用方向与图片风格，也可套用提示词或活动模板。模板与复制只带入可用字段；过期、停用或跨作用域引用需要重新选择。参考图可选，只能引用授权且可用的图片，不能凭随机文件名确定人物或产品身份。

活动冻结实际风格、版本和资料。历史活动、已有修订和复制的生成测试保持原快照；修改平台默认不会改写它们。风格不能覆盖授权、敏感规则、结构化输出或内容安全要求。

预设的实际文案与图片效果需要使用自己的模型验收。测试台可以临时比较提示词，参见[平台生成测试台](generation-lab-2026-09-28.md)。
