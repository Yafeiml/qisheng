# 核心数据模型

以 `prisma/schema.prisma` 与已登记迁移为精确结构来源。本文说明当前业务边界，不把历史兼容表当作仍可操作的功能。

| 领域 | 主要事实 |
| --- | --- |
| 组织 | Tenant、Enterprise、AdminUser、角色授权、GlobalUser、EnterpriseMembership |
| 身份 | 密码哈希、管理会话、管理员创建的成员网页账号及明确绑定关系 |
| 资料 | 素材版本、附件、授权、可用状态、解析任务、片段与检索索引 |
| 活动 | Campaign、受众及配置快照、GenerationRun、逐成员工作项 |
| 交付 | EmployeeContent、生成图片、成员任务、版本确认与修订历史 |
| 回填 | 发布链接、规范链接键、验真结果、人工处置和指标证据 |
| 治理 | 平台设置、模型路由、能力验证、调用记录、审计和运行事件 |

## 不可变与归属

资料修改产生新版本。活动冻结实际使用的资料、规则和风格，重试与修订遵守原活动边界。图片附件、成员任务和回填均有明确的工作空间与企业归属，不通过展示名称猜测归属。

管理员账号与员工自然人身份不混用；管理员创建的员工网页账号只绑定指定成员。未验证手机号不能作为跨企业身份合并依据。

工作项版本、租约和幂等键共同防止重复交付。存储容量的预留和核对独立管理，生成重试仍需符合审核与授权要求。

## 历史兼容

合同、开通审批和组织同步已退出运行模块，相关历史结构不代表仍开放操作。已退休的余额和购点结构通过维护迁移删除。既有迁移文件与已登记 SHA-256 不得重写；删除结构的升级必须先停止旧应用，不用 `db push` 覆盖历史。
