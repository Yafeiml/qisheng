# 可选公开内容回读接入

默认由管理员人工复核发布链接。自动回读是获取公开笔记和指标的可选增强功能，不作为安装或生成的前置条件。启用前配置自己的数据接口与 Token，完成真实样本验证，并确认每日请求上限。本文不包含已运行节点的私有地址、白名单、账户、Token 或上线回执。

## 一致性边界

1. 员工回填先保存链接与提交时间，外部请求不占用主 API 长事务。不能提取可靠笔记 ID 的短链保持待核查，不把短码当作 ID。
2. 主服务在事务中创建持久工作单，到期节点原子领取，使用租约和幂等回写；任务状态不能因多节点重放重复核销预算或重复计入指标。
3. 节点只获取工作单所需的公开内容，不读取员工账号凭据。同机模式的供应商 Token 由主后台加密保存，仅在领取有效任务时下发给指定签名节点；普通节点接口和后台查询不返回 Token。高级独立节点继续在节点本地安全保存其凭据。Token 不回显到页面，也不进入业务快照、镜像或日志。
4. 响应必须对应同一笔记 ID。缺失点赞、评论或收藏数保持未知，不写成零；观察时间与提交时间分别保存。
5. 主 API 校验租约、任务归属、提交状态、时间窗和字段上下界。迟到、替代任务和过期租约不能覆盖新结果。
6. 技术失败、认证失效、解析变更、证据不足分别处理。供应商故障不能认定员工未发布；调用结果未知时停止自动重复付费，交由人工复核。

## 节点安全

节点身份使用独立强签名密钥、时间戳及防重放校验，可单独吊销。控制面应限制在可信网络，不公开未设密面板。主 API 地址、节点绑定地址及初始访问来源由安装者配置，不能照抄他人私网拓扑。

自动回读默认关闭。管理员在主后台保存数据接口与 Token，明确确认后测试一个有权核查的笔记样本；配置变化后原验证失效，需重新验证才能启用。样本测试可能收费，保存、开关切换和健康检查均不得自行测试供应商。旧的 `PUBLICATION_READBACK_ENABLED` 与独立节点设置保留兼容，明确保存的后台开关优先。

仓库的可选实现说明见[采集节点](../../packages/xhs-api-collector/README.md)。可使用同一主机、同一 Compose 网络的可选采集容器，无需独立服务器或节点控制台。同机容器只读取专用签名密钥文件，不能挂载包含数据库、JWT 和加密主密钥的完整配置目录。旧的独立节点面板仅供高级部署使用。

部署者自行填写兼容的公开 HTTPS 笔记详情接口和自己的 Token，项目不附带供应商地址或凭据。接口支持通用 JSON 和双层 JSON 响应，请求和响应校验继续使用防 SSRF、笔记 ID 匹配及有界响应读取。公开内容存在不代表已经核实发布账号归属或全部独立图片，见[回填规范](../10-发布回填验证规范.md)。
