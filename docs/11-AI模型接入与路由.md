# AI 模型接入与路由

自托管管理员使用自己的模型供应商账户。在平台控制面添加连接、加密凭据和模型，选择文本、图片、资料理解与可选向量检索用途；普通企业管理员和员工不能读取供应商密钥。

## 配置步骤

1. 在“模型配置”添加供应商 HTTPS Base URL 和自己的 API Key。
2. 读取或登记模型，核对其声明能力与供应商实际支持的协议。
3. 为文本、图片和资料理解选择模型。图片理解需要 VISION 或 MULTIMODAL 能力，只有文本或生图能力不能替代。
4. 为图文安全审核选择支持图片输入的模型或独立审核服务，并完成[审核验证](内容安全审核.md)。
5. 检查真实功能验证与路由门禁。实际生成和功能验证可能产生供应商费用。

未配置外部向量模型时可使用基础字符检索；它不是语义检索，也不能替代资料理解或图文安全审核。

## 路由与历史

业务模块声明任务类型，由统一路由按企业覆盖、工作空间覆盖、平台默认的顺序选择。覆盖表示适用范围，不代表企业管理员获得平台模型管理权限。活动冻结实际路由和规则；管理员后来修改默认配置不会改写旧活动快照。

主模型重试与备用模型切换只能按已冻结策略执行。参考图编辑请求失败不能静默改成无参考图生成，供应商返回错误不能伪装为成功。

## 能力与健康

连接探测只判断接口可达性，不等于真实文案、生图或图文审核已验证。配置变化需重新核实相应能力；连续实际任务失败与供应商短期熔断分别治理，见[动态门禁](动态模型门禁.md)。

## 成本与安全

每次调用记录实际模型、策略版本、状态、延迟、重试、用量及可核算成本。未知价格或用量不能显示成零费用；不同币种不能不经转换直接相加。这些记录用于供应商成本观测，不影响活动执行资格。

密钥以应用密钥加密保存，只显示是否配置及掩码，不进入普通日志、审计正文或活动输入。外部地址执行网络安全检查，不能为兼容网关关闭整体防护。升级必须沿用现有加密主密钥，不能重置后丢失既有凭据。

真实模型评测见[AI 基准](../benchmarks/ai/README.md)；本地协议测试不代表真实输出质量。
