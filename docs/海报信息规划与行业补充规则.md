# 海报信息规划与行业补充规则

从 2026-10-10 起，生成链路先规划图片中的信息，再安排画面。继续使用小红书分享风格，默认形成适合手机阅读的 3:4 品牌海报：一个主标题、一条准确主体身份，以及两三个与活动目标直接相关、有授权资料依据的短要点。资料不足时减少要点；用户明确要求极简或无字时尊重其要求。

## 通用信息规划

主体可以是人物、产品、设备、服务或机构。姓名、型号、正式名称及身份须对应本次目标，不猜测身份，也不借用其他主体的照片或资料。要点优先采用具体事实，保留数字、单位、时间、适用条件及主体归属，避免空泛的“先进”“领先”口号。没有依据、口径冲突或主体含糊的信息不展示。

母版规划、员工文案与生图提示词、最终生图请求均接收同一份规则和冻结的授权资料。规划通过已有的 `imageDirection`、`imagePrompt` 输出传递，不增加额外模型调用，也不增加企业运营人员的选择项。Logo 继续由系统使用原图在左上角合成。

## 行业管理

平台管理员进入“行业管理”(`/platform/industries`)，在行业卡片点击“编辑规则”。补充规则最多 6000 字，可以保存或清空；清空后只应用通用信息规划。只有查看权限的管理员可查看规则，不能修改。

行业规则用于指出优先寻找哪些事实，以及这些事实的表达边界，不能替代企业资料、敏感规则或内容安全要求。企业行业沿用现有资料字段，运营人员无需再次选择行业或风格。没有行业、历史自定义行业无法对应当前目录、或未配置补充规则时，使用通用规划。

规则修改有权限校验、并发版本校验和审计记录。其他管理员已修改同一规则时返回冲突，页面保留本次编辑内容并提示刷新，不覆盖他人的修改。

## 医疗健康初始规则

迁移为“医疗健康”行业初始化补充规则，其他行业默认留空。医疗规则从主题中选择相关的客观身份、具体设备型号、技术原理或诊疗流程，保留正式职称、职务、奖项及认证范围。

数字信息保留个人或机构、术式、例数或眼数、统计时间和来源口径，不能把机构总量归给个人，或把从业年限等同某术式经验。来源缺失、主体不明确或口径冲突时省略。规则同时提醒模型结合发布主体、渠道和用途判断表达，不能把事实真实等同于已经获得医疗广告审查批准，不作疗效保证、患者推荐、治疗前后对比或无依据的排名。

## 生效与历史兼容

新活动在创建事务中冻结所属行业的名称、规则正文和更新时间。新建平台生成测试也冻结规则。管理员之后修改规则，不会改变已有活动或测试的冻结输入；图片、文案及同时重生成均沿用原活动规则。已有快照缺少行业字段时兼容读取，不自动补入当前行业规则。

未修改过的内置图片基础提示词升级为新的海报信息规划；管理员自定义的基础提示词保留原文，通用规划仍在生成请求中明确给出。历史活动冻结的风格提示词保留原样，不回写历史数据。

新增迁移 `20261010080000_industry_generation_guidance` 仅增加带空字符串默认值的字段并初始化医疗规则，已登记兼容性校验值。旧客户端读取与插入、迁移事务回滚、本地数据库应用均已验证。

## 验证和发布

已覆盖行业编辑权限、空值及长度校验、并发冲突、审计、规则冻结与 JSON 持久化、生成请求中的规则和原始事实、三种重生成模式以及旧输入兼容。行业管理的桌面与 390px 窄屏保存、重新打开、清空和只读查看通过浏览器检查，API、Web、Worker 及共享生成包构建通过。
