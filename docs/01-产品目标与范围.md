# 产品目标与范围

企声发布帮助企业用真实、已授权的素材组织营销活动，为员工分别生成图文。企业完成资料维护、生成与人工审核；员工领取任务、确认真实、手动发布并回填链接。

## 默认闭环

1. 使用同一 Compose 项目部署 API、Web、内容 Worker，连接 PostgreSQL 和 Redis，默认使用本机存储，可选 S3。
2. 通过网页安装向导创建管理员和组织即完成安装，默认本机存储；管理员随后在后台配置模型、审核和可选服务。
3. 添加成员、上传文字依据及可选图片，使用通用提示词、方向、图片风格或活动模板创建活动。
4. 生成后人工审核，立即开放或预约开放；同企业活动允许重叠。
5. 管理员为明确的成员身份创建网页账号，成员用账号密码在员工网页完成领取和回填。

## 保留与退出

保留平台、工作空间和企业权限隔离，版本化资料与授权校验，模型路由、图文生成、安全审核、人工批准、任务分发、回填和内部效果统计。员工只访问本人任务。

CAP、邮件、短信兼容登录、微信小程序、外部向量检索和公开指标供应商均不是首次使用的安装条件。CAP 默认关闭；开启前必须配置服务 Endpoint 和 Secret Key。

支付、充值商品、赠送与优惠、合同经营、官网申请与客户审批、企业微信/飞书/钉钉组织同步不再提供运行入口。旧商业记录和历史迁移保留，不因移除功能而删除数据。专用主机与私有发布工具不属于安装前提。

生成结果需要人工判断事实、授权和渠道要求。系统内部 GEO 覆盖表示已生成内容对实体或问题的覆盖，不代表外部搜索排名、曝光或成交。
