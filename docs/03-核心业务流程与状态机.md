# 核心业务流程与状态机

## 素材

新增文字或图片资料后异步整理。处理状态与可用状态分别记录：技术失败不会伪装为缺少资料，待补充资料不会被生成引用。修改已生效资料产生新版本，历史活动保持原快照。

## 活动与生成

1. 企业选择受众、输入主题和传播要求，选择可选模板、内容方向及图片风格。
2. 预检权限、成员资格、可用资料、模型能力和队列。正式创建在事务中再次检查并冻结生成输入。
3. 活动与生成工作项保存冻结输入；Worker 按工作项执行生成、图片交付及安全审核。
4. 失败工作项可按规则重试；成功工作项重放不重复生成或交付。审核阻断需要处理，不自动当作通过。
5. 全部必要内容就绪后人工审核并批准，按实际开放时间解锁任务。

| 活动阶段 | 主要含义 |
| --- | --- |
| DRAFT / GENERATING | 草稿或正在生成，不向员工交付 |
| GENERATION_FAILED | 存在生成失败，可检查并重试 |
| REVIEW_PENDING | 等待人工审核 |
| APPROVED | 审核通过，等待开放或生命周期推进 |
| ACTIVE | 成员可以执行任务 |
| COMPLETED / CANCELLED | 已结束或已取消，保留历史 |

活动不再要求提前 8 小时，也没有全企业活动窗口互斥；操作边界见[排期规则](campaign-lifecycle.md)。

## 员工与回填

员工网页只展示本人任务。领取时重新校验成员资格、任务时间、内容版本和授权；需要的真实性确认绑定当前内容版本。员工手动发布后回填链接，服务端清洗链接、检查唯一性并按已启用的验证策略处理。

外部内容不可获取或供应商异常不等于员工违规；应保留待复核或技术失败状态。内部生成、确认、回填与外部验真是不同事实。

## 幂等与取消

创建、重试与取消通过事务、工作项版本和租约保持幂等。取消停止未完成工作项和未开放的任务，保留已完成内容与历史审计，不重复生成或交付。
