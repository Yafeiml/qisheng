01 / PROVIDER

供应商接口

正在读取配置…

这是供应商的笔记详情接口，不是企声主服务地址。节点以 GET 请求自动追加 noteId；请勿在地址中放入密钥。

可填写 Bearer 或 Token 前缀；无前缀时按 Token 发送。密钥加密保存在本机，不会回显。

接口需要返回什么内容？

仅支持上述 GET 查询和以下 JSON 协议。自行选择的供应商若使用其他参数、鉴权或响应格式，需要先通过自己的网关适配。

{
  "noteId": "请求中的笔记 ID",
  "title": "笔记标题",
  "body": "笔记正文"
}

可选字段：authorId、publishedAt、imageCount、hashtags、likes、comments、favorites。样本验收还需非空标题与正文，以及点赞、评论、收藏数量。仍兼容旧版双层 JSON 响应。地址或 Token 变更会暂停节点，需重新验收样本。
